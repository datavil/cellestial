# Cellestial v1.0.0 Plan

The remaining 1.0.0 work should focus on hardening the current feature set,
not adding new features.

## 1. Audit AI-generated / AI-modified functions

Review the functions listed in `plans/audit_AI.md` line by line.

Success criteria:
- Public behavior is intentional and documented by tests where needed.
- Edge cases are either handled or deliberately rejected with clear errors.
- No unnecessary abstractions or speculative flexibility are introduced.

## 2. Improve public error messages

Make user-facing errors specific, actionable, and aligned with Cellestial's
predictability principle.

Priority examples:
- Singular functions should guide users to plural functions when given multiple keys.
- Missing keys should say where Cellestial looked.
- Wrong data types should say what was expected and what was received.

Success criteria:
- Common misuse produces helpful errors.
- Tests cover the most important error paths.
